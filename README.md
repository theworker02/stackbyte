# stackbyte

Stack timestamps and byte durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/stackbyte/

## Install / run

```bash
git clone https://github.com/theworker02/stackbyte.git
cd stackbyte
node src/cli.js
node --test
```
